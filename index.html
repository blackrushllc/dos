The Boringly Simple File System.

DOS is a high-performance, internet-native Disk Operating Service. It allows you to mount remote file shares directly into your operating system's native file explorer as if they were local hardware.

Built with Rust for uncompromising safety and speed, DOS leverages user-space filesystem technologies like FUSE and WinFSP to provide a seamless, driver-less experience across Windows, macOS, and Linux.

The Syndorela Ecosystem

DOS is a cornerstone of the Syndorela ecosystem. We believe in empowering users to distribute virtual disk drives in any manner they see fit, across all kinds of environments. Whether you're bridging legacy infrastructure or building the next generation of distributed apps, DOS is the fabric that connects your data.

Infinite Use Cases

Legacy Migration Bridge

Map network drives for legacy desktop apps that depend on local disk I/O. Use DOS as an intermediate layer for code generation and data migration, allowing old code to run on a modern tech stack without modification.

Hybrid Cloud Orchestration

Expose cloud-based storage buckets as local drive letters for legacy build systems and CI/CD pipelines that require standard filesystem paths.

Global Media Workflow

Enable real-time collaboration on massive video assets. Producers in London and editors in Tokyo can work on the same P: drive with automatic conflict resolution and high-speed range reads.

IoT Edge Aggregator

Collect logs and telemetry from thousands of remote devices directly into a mounted share. Your analytics engine sees a single, constantly growing local directory.

Ephemeral Dev Environments

Instantly provision project-specific virtual drives for new developers. One dosctl join command and they have every asset they need, perfectly mounted and ready to go.

Secure "Air-Gapped" Over IP

Create encrypted, private shares that only exist when the DOS client is active. Perfect for temporary high-security collaboration without the footprint of a traditional VPN.
